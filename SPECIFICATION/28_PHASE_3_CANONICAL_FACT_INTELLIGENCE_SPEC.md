# Part 28 — Phase 3: Canonical Fact Intelligence Specification

**Status:** Phase 3 implementation complete, tested, uncommitted pending this specification. **Baseline:** [23](23_RUNTIME_GOVERNANCE_MIGRATION_BASELINE.md), frozen at tag `runtime-governance-phase-2`.

## Purpose

Canonical Fact Intelligence answers one question for each fact this platform already reasons about: **what is this fact, whose definition of it is authoritative, and how has that definition changed?** It does not resolve a fact's current value (Resolver Intelligence, [29](29_PHASE_3_RESOLVER_INTELLIGENCE_SPEC.md)) and it does not decide whether a value is permitted (Runtime Authority). This document catalogs the facts that already exist in the codebase today. It invents none.

## What this catalog deliberately does not do

- It does not introduce a Fact Registry, a Fact Version field on any row, or a new table. Every "Meaning Version" above is `1` because no fact in this platform has ever had its definition change in a way that required a second version to coexist with the first — versioning infrastructure with nothing yet to version would be exactly the kind of speculative build this phase's directive forbids.
- It does not resolve `action`'s and `currency`'s asymmetry (one enumerated, one not) into a false consistency. `currency` having no enumeration is a real, current gap, carried forward honestly into the Gap Analysis rather than papered over with an invented vocabulary this phase has no requirement to build.
- It does not claim `resource`/`agent` (scope-narrowing) are canonically identified beyond "non-blank string" — because today, in the actual code, that is all they are.

## Relationship to the one code change this phase made

`domain/compiler_v2/compiler_v2.py::FinancialVocabulary.known_actions` previously hand-copied `action`'s three values as an independent literal, rather than referencing `scope_vocabulary.py::KNOWN_SCOPES` — two definitions of the same fact's identity, kept in sync only by the author remembering to update both. This is precisely the failure mode Canonical Fact Intelligence exists to name and prevent. The fix (documented fully in the Migration Report, [33](33_PHASE_3_MIGRATION_REPORT.md)) makes `KNOWN_SCOPES` the fact's one real definition and `FinancialVocabulary` a consumer of it, not a second author of it.
